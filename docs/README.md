## Keyboard and commands

| Shortcut | Action |
| --- | --- |
| `⌘⇧R` / `Ctrl+Shift+R` | Open chat |
| `⌘⇧.` / `Ctrl+Shift+.` | Send the editor selection to the active room |
| `Enter` / `Shift+Enter` | Send / newline |
| `Esc` | Stop the debate |
| `@Name`, `@all` | Pick who answers first |
| `/stop` `/reset` `/dm Name` `/model Name id` `/room Name` `/guardrails` `/help` | Composer commands |

All commands are in the palette under **Roundtable:**.
